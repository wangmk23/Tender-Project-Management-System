# 采购方式与界面偏好（v5.8.40）

在“系统设置 → 项目流程”按适用采购制度管理方式。旧版八种方式保留原名称、数量与阶段配置，制度显示待确认；可在未确认制度时维护旧流程，管理员确认后才能用于新建项目。分类遇到同名冲突可先对比并手动处理，不自动合并历史配置，见[审查修复说明](flow-review-fixes.md)。跨制度可同名，同一制度内名称唯一。已被项目或采购包引用的方式只能停用；停用不影响已有项目。

数量规则可选“不固定最低数量”或配置最低数量，并附例外情形与说明。配置属于业务默认值，不直接代表法定最低数量。报名、已提交并接收、有效投标三个阶段分别计数；名单待核对不会按零家处理。数量不足时需填写原因或选择适用例外并人工确认，不自动流标。名单或规则改变后需重新核对。

采购方式列表通过“基本设置”和“编辑流程”分别进入，流程以宽版居中弹窗展示左侧总览和右侧编辑，详见[流程编辑说明](workflow-editor.md)。

默认流程可用通用模板或独立模板，只作用于之后新建的项目。在项目信息点击“调整本项目流程”，先预览再保存。已完成阶段保持原记录；有业务资料、检查项、附件、保证金起算或业务期限依赖的阶段不能直接移除。并发修改会要求重新预览。

项目和重新采购的方式信息以稳定标识及快照保存；之后修改名称和默认规则不批量改写已有项目。保证金默认规则按方式标识保存，模板不能移除启用规则的起算阶段。期限助手仅提供制度建议，仍需核对、保存和启用；不因方式名称自行套用法律期限。

项目导入模板附“采购方式目录”参考页。可按名称与制度填写，或复制采购方式标识；同名缺少制度、未知和停用方式会逐行报错。参考页不会作为项目数据导入。导出追加标识与制度，名称以项目或采购包快照显示。

“常规与外观”内的个人设置即时生效，按当前账户、设备及访问地址保存。旧设备偏好只迁移给首次使用的账户一次；其他账户从默认值开始。浏览器禁用存储时会明确提示仅本次会话有效。登录前仅使用设备主题选择。

四主题和跟随系统、紧凑显示、附件预览、字号、动画、默认首页、侧栏字段/排序、日期显示、周起始及节假日装饰均不更改业务数据。系统减少动态效果优先。名称和状态始终显示；日期格式不改变输入、API、导出和邮件日期。关闭休/班装饰不影响工作日计算。

“恢复界面默认”只恢复当前个人偏好。登录副标题仍由管理员单独保存；导出年份移到“文件与数据”，导出目录、邮箱、账号、许可、密钥和年度安排不随个人恢复改变。

公开包采用自建密钥；已有私有授权部署使用对应兼容成品。历史核心仍为编译运行时，源码包含可编辑界面和后端扩展，不声称完整核心源码已恢复。
