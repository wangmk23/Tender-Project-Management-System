# 竞价办理与质量修复说明

适用版本：v5.8.41。修复第一轮自动化质量审查中的六项问题，以及网上竞价办理拦截和保证金邮件明细显示问题。

## 一次报价竞价

旧流程快照可能给多个标准阶段重复附加竞价模块，后台因而误把前面的阶段当成报价核对阶段。现在按照标准阶段的用途判断；自定义阶段仍按其业务模块办理。不改写已保存的流程、阶段完成日期、供应商记录或原始报价。

保存当前阶段时，不会因为其他历史阶段缺少后续版本新增的台账标记，要求撤销历史完成记录。已有的业务确认仍受保护：撤销其真实确认内容时，需要先撤销对应阶段完成状态；已核对报价变更仍须按原更正流程办理。

完成一次报价竞价前，需核对报名审核参竞名单、竞价开始与截止时间、平台实际结束时间、结束原因及结果凭证。实际参与名单与报名审核有不同用途，确认实际参与不能代替报名审核。缺项会逐项显示，并定位可填写的字段；失败时保留当前输入。金额没有报价时留空，不自动记作零元。到截止时间结束允许部分供应商未报价；选择“全部合格供应商已报价”时必须均有有效报价。

## 邮件提醒

自定义采购方式流程和项目阶段快照都可以作为提醒节点。已有订阅继续保留；停用、移除阶段和同名阶段按界面来源说明核对，模板调整不会自动覆盖历史项目。

保证金提醒逐项列出公司与实际待退金额，再显示合计。同一公司在不同采购包、不同截止或状态下分别列明，不把公司名称与金额合并后失去对应关系。已经退清的余额不会进入待退明细和合计。银行转账仍需实际办理后登记。

## 日历与键盘

普通阶段日历事项直接打开对应项目的对应阶段。加载失败显示可重试反馈；已移除或禁用的阶段不伪装成可编辑状态。保证金复核和其他专用事项继续进入其原有处理入口。

阶段面板初始焦点落在可见、可操作的控件；折叠的备注不再抢占焦点。支持 Tab、Escape 和关闭后返回触发按钮。

## 附件与预览

Excel 预览使用本地固定版本 SheetJS 0.20.3，来源与校验记录见 `src/project_manager/static/libs/xlsx/PROVENANCE.json`。大文件、多工作表及大网格受预览资源上限保护，超限时提供下载处理；不执行工作簿公式。

上传文件在加密写入之前检查扩展名对应的格式特征；OOXML 与 ZIP 进行结构和资源边界检查。假 PDF 等不匹配内容会被拒绝，现有附件不自动重写。此校验用于识别格式错误，不等同于完整恶意软件扫描。

空计划时间是正常状态，不输出解析告警；非空异常日期仍有受控诊断。

## 验证边界

测试使用隔离的虚构项目与本地邮件替身，不读取或修改实际业务数据库，不重启现有程序，不发送真实邮件。验证记录随中文版本成品交付；浏览器与无头成品检查不等同于原生客户端人工验收。历史核心仍为编译运行时，公开包不包含私有兼容运行时、密钥或真实数据。
