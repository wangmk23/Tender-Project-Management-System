# 时间控件统一

v5.8.23 将阶段计划、完成和批量计划中的日期与时分组合为一个控件。日期与时分共用边框、背景和焦点提示，中间仅保留分隔线。仍可分别使用日历和时间选择器，也可通过键盘输入。

快速完成窗口采用紧凑的阶段标题、完成时间和操作区；取消与确认位于同一行。明暗主题使用系统颜色，桌面和窄屏保持一致高度。窄屏批量计划中的组合控件占据完整内容列，避免原有网格样式使日期、时间错列。

保存逻辑未改变：历史记录只有日期时不会补写时分，未修改的计划保留原精度，新增时分按分钟保存。

## 验证范围

- 前端 297 项回归通过，包含实际快速完成模板、编辑面板和批量计划结构的明暗主题及窄屏布局检查。
- 阶段分钟精度、后台调度、版本编译和公开构建相关的 100 项 Python 回归通过。
- 隔离候选 EXE 的实际 HTTP 页面检查 15 项通过，覆盖保存与重开、明暗主题、390/1366 像素窗口、完成标题对比度与控件边界。
- 使用三个模拟供应商的隔离项目，观察真实后台调度完成已到期且启用自动完成的报名阶段。完成时间、审计记录及重启后的结果均保留，人工阶段不被完成。

真实后台验证只确认模拟项目的自动完成路径正常，不能据此判定其他部署中逾期报名的原因。相关个案仍需核对实际运行目录、项目阶段快照、计划时间及自动完成启用时间。本版不包含未经确认的自动完成逻辑修改。
