# 待办与交互优化

本轮从《系统改进建议》的 23 项建议中选择现有操作中能够确认的缺陷与重复展示进行处理，未增加采购流程、审批层级或新的业务记录。

## 界面与操作

- 总览先展示待办节点与风险事项。待办可按全部、逾期、今日、7 天内筛选，点击节点进入对应阶段；“全部待办”在当前页面打开明细窗口。
- 进行中项目保留五条预览，完整列表从统计入口查看。取消首页重复展示的未开标长列表，保留未开标统计与明细入口。
- 侧栏和快捷检索共享项目索引，可匹配编号、名称、采购人、采购方式、显示状态及当前阶段。未增加新的搜索语法。
- 项目当前行动展示对应阶段、负责人和计划时间。没有指定负责人的阶段标明“未指定”，不推断负责人。
- 新建项目先填写名称、编号、采购方式和采购人。预算、年度、负责人、保证金及采购包放在“补充资料”内；创建和取消操作固定在弹窗底部。

## 已确认的缺陷

- 长按监听原先在被动 touchend 中取消事件，且未完整处理滚动、取消手势与多点触控。现在清除无效手势，并仅拦截长按目标随后产生的一次指针点击；键盘激活与下一次正常点击保留。
- 最近关键节点倒计时原先会纳入已从模板移除的历史阶段。现在倒计时、待办和当前行动都排除这些阶段，历史资料仍保留。
- 新表单折叠标题纳入弹窗焦点管理，展开后 Tab 可以进入可选字段；当前行动的负责人、时间使用普通文字，避免继承旧徽章样式。

## 验证范围

验证使用隔离数据、复制的许可证或新建公开密钥。原运行程序、业务数据、SMTP 凭据、附件与授权文件不作修改。兼容构建对原 licensing、data_security、公钥与许可状态函数进行比对。

前端回归覆盖长按与随后的点击、取消与移动手势、倒计时与待办集合、筛选、检索、折叠表单、键盘顺序、重复提交和采购包部分保存失败后的重试。浏览器检查覆盖明暗主题、1280px 桌面与 390px 窄屏；实际 EXE 检查覆盖总览明细、阶段分钟保存、表单创建与可选字段持久化。

自动化浏览器截图属于隔离环境检查，不能替代实体触屏手势或人工桌面验收。本轮不发送真实邮件，不改变邮件提醒或授权工具的行为。详细执行结果随本地交付记录保存。

## 暂未采用的建议

复杂审批引擎、独立任务表、完整操作回滚、通信协作及自动生成业务文件没有足够证据支持本轮增加。现有检查清单、阶段模板、提醒与审计功能继续使用；统计扩展需要先明确数据来源与时间口径。

历史核心后端仍以编译运行时提供，本轮没有恢复完整核心源码。公开版使用自行初始化的密钥，与已有私有授权的兼容升级版分别交付。
