# 时间控件与业务弹窗

项目页面的日期、时间和日期时间字段共用主题选择器，保持原输入字段的 ID、数据格式、权限和提交接口。阶段完成与计划日期仍在同一弹层选择日期和时分；报名获取日期只显示日历；邮件发送时间只显示时分。已有秒或小数秒精度会保留，需要秒的字段显示秒列表。

| 检查位置 | 交互 |
| --- | --- |
| 阶段完成、计划、批量推进及计划 | 同一弹层选择日期与时分 |
| 报名获取、通知书领取、开票、归档寄出 | 主题日历，保存日期字符串 |
| 澄清发布日期及调整截止时间 | 日期或日期时间，取消不改写原值 |
| 质疑收到、答复、办理期限与过程事件 | 日期或日期时间，动态新增行也使用相同控件 |
| 网上竞价报名截止、报价及实际结束时间 | 同时选择日期与时间，保留旧秒精度，快速填充同步显示 |
| 邮件提醒发送时间 | 小时与分钟，不增加日期 |

月份箭头、关闭按钮与字段日历图标使用固定 SVG 尺寸并居中。共享表单弹窗在圆角框内裁切背景，正文独立滚动，页脚保持可用；日期选择器放在独立浮层，避免被正文裁切。明暗主题、窄屏和弹窗内键盘操作采用同一套样式与焦点管理。

选择先保存在弹层草稿中，确认后一次写回。取消、Escape 或外部关闭不提交。禁用与只读状态、必填、日期范围和输入步长继续采用原字段约束；空值、仅日期历史记录及未修改的精度不擅自转换。嵌入式文档和表格预览的第三方编辑器不改写。

后台可能返回六位小数秒，而 HTML 原生日期时间字段只接受毫秒表示。组件保留原字段类型和 ID，以浏览器支持的表示进行原生约束校验，同时为现有通过 JavaScript 读取字段值的保存逻辑保留完整精度，避免回填时被清空或保存时截断。

报名自动完成个案的排查仍按用户要求暂缓，本版未修改相关业务规则。成品验证采用隔离数据与无头浏览器，不代表实际使用电脑的人工桌面验收；未发送真实邮件。
