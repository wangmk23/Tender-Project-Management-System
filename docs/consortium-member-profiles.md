# 联合体成员资料与表单修复

适用版本：v5.8.31。

## 成员资料

在报名编辑窗口选择“联合体投标”后，各成员用可展开卡片分别填写单位名称、地址、法定代表人、联系人、电话、邮箱及备注。仅单位名称必填。新增、删除及调整顺序时保留其他成员的未保存输入，邮箱错误会提示并保留草稿。

附件仍在整条报名的统一附件区域上传，不新增成员附件入口。联合体连同所有成员仍只计一家报名，所属采购包仍由这条报名统一确定。

旧成员名称和顺序保留，升级只增加可选资料列，不编造联系人。旧客户端仅提交成员名称时，已有同名成员详情保留；新表单明确清空某字段后可正常保存为空。修改成员联系方式或备注不改变投标主体指纹，不会因此要求重新核对参与名单。成员名称或组成改变时仍按原规则核对。

## Excel 导入导出

报名主表保留原格式和“联合体成员”名称列，模板及导出另附“联合体成员资料”工作表，每成员一行。通过项目编号、所属包号、牵头单位及成员单位名称关联到主报名，六项资料单独列出，附件继续列在主报名附件表。

旧版只有主表和名称列的 Excel 仍可导入，不清空已有成员详情。导入既有报名时只补空白资料，不覆盖手工填写的信息，不改变成员顺序或报名家数。成员资料须与主表中的成员对应；未知成员、重复明细或无效邮箱会拒绝对应的报名组并显示工作表与行号，组内数据库写入失败会回滚。

成员表缺少关联字段、采购包或项目编号不匹配时，在写入前拒绝导入。跨项目导出文件用于某项目导入前，应在主表和成员表同时保留该项目对应的记录，避免混入其他项目。没有成员资料表时，沿用旧版导入流程。

## 未参加时不评有效性

“投标有效性”仅在选择“已提交并接收”后显示并可操作。未参加、未提交或文件未接收时，不显示有效性待确认或有效/无效标签；回到已提交状态后须重新核对，不会自动恢复为有效。

未提交文件时，内部保留兼容的未评定状态，不新增历史数据迁移或批量改写。已有缴纳和退还记录独立保留，不能因未参加而抹除应退款项。

## 主题与图标

已复现并修复联合体成员、质疑/投诉动态输入行缺少主题样式的问题；排序箭头使用现有 SVG 图标系统。成员长名称可换行，窄屏按钮独立排列；质疑行删除按钮不覆盖输入框。修复限定在业务表单区域，复核了复选框、文件输入、隐藏的日期源字段、外部文本框和表格插件边界。
