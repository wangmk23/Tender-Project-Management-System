# 图标、邮件设置和授权控件复查

用户截图显示了阶段图标溢出、邮件输入错位、批量推进仍显示原始 Emoji，以及授权工具原生边缘偏白的问题。

## 修正

- 图标预览包裹原下拉框后，原先依赖直接子元素的 CSS 失效。改用包装层内的控件规则，固定阶段选择器 38px、自绘图标 20px，并保持图标选项原值。
- 展开选项和收起预览共用自绘图标；动态替换采购方式对应阶段时刷新预览，普通业务文本与未知图标保留。
- 检查进度、任务、阶段完成切换、入围状态和附件下载，补齐遗漏的自绘图标。
- 邮件表单连接参数等宽，账号和发件邮箱分列，时间与提前天数对齐；说明单独占行，收件邮箱铺满组宽。密码保持空值渲染与 Windows 加密保存。
- 授权工具显式设置 clam 各状态颜色，以圆角图像元素替换原生控件表面，保留原生文字、输入及事件。卡片内容缩进露出圆角，状态提示与滚动条统一配色。

## 验证范围

- 前端 252 项通过，包含 Chromium 在 1280、820、390px 下的尺寸、对齐、溢出、下拉展开及键盘检查。
- Python 567 项：547 通过、20 因平台或缺少对应测试运行时跳过；公开授权专项 31 项通过。
- 公开授权 EXE 六项隔离初始化、签发、错误磁盘拒绝检查；系统 EXE 十三项隔离启动与项目流程检查通过。
- 本地授权工具十四项源码检查、两个实际 EXE 的隔离诊断通过；原绑定工具的指纹及签名输入协议一致。
- 原生 Tk 三页在 960×720 和 840×640 下检查尺寸，测试窗口置于屏幕外，桌面焦点未改变。未将示意图或无头浏览器截图当作实际桌面人工验收。
- 本地兼容升级的原许可校验、原公钥和数据加密模块保留，许可与状态文件只读验证。生产配置、密钥及邮件测试记录不进入公开包。
