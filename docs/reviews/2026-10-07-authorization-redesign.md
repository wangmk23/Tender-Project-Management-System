# 授权中心 1.5 界面重设计与复查

## 改动

原界面把签发、设备信息、密钥维护堆在同一窗口。本次改为左侧导航的三个页面，签发页保留数据目录、使用单位、期限与设备选择。自由运用版远程机器码、自定义到期日、备注按需显示；绑定磁盘版保持本机限制。表单切页不丢输入，复制使用页内提示，主签发按钮固定在底部。

采用系统的深色背景、蓝色主按钮、统一尺寸的自绘彩色图标与圆角卡片。Logo 保留。修复全局字体选项覆盖 ttk 标题样式的问题，让标题、说明和正文恢复层级。默认 960×720，最小 800×560；常用字段在默认窗口内完整显示。

授权格式、签名算法、密钥存储与磁盘验证规则没有改动。应用运行时仍为 v5.8.14，本次仅重建两个授权工具为 1.5。旧密钥不会被自动重建或覆盖。

## 验证范围

使用隔离的测试目录验证表单保留、远程目标清除、自定义日期、备注展开与复制反馈；执行授权源码测试及 Python 回归。两个 EXE 另行检查密钥初始化、共享密钥签发、错误磁盘拒绝及包内隐私扫描。

通过实际 Tk 窗口的控件坐标检查两种模式、三个页面和最小窗口的签发按钮位置；检查期间没有改变桌面焦点。图示依据实际控件坐标绘制，属于布局示意，不作为真实桌面截图。本次没有进行用户可见桌面的人工鼠标操作验收，运行中的业务系统没有切换。

## 交付

先完成本地中文命名成品、源码快照、仓库备份、版本入口和交接记录，再发布 GitHub。公开下载资产保留英文名，本地校验清单记录中文名与对应英文名的相同 SHA-256。历史交付保留。

源码边界仍为可编辑前端、后端扩展、授权工具和构建工具；历史应用核心以编译运行时提供。
