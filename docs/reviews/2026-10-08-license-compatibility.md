# 授权兼容与发布复查

本地已有授权的系统不能直接替换为自建密钥的公开运行时：二者的产品标识、公钥来源不同。已添加兼容升级构建工具，用原部署运行时作为输入，保留其 licensing、data_security 模块、授权状态函数和嵌入公钥，更新界面与受控扩展。受保护模块变化时构建校验拒绝交付。

本地交付按用户指定目录组织，系统成品、源码和交接在项目系统目录，授权工具成品、源码和校验在授权工具目录。公开版与原授权兼容版明确标注用途；本地先完成，再发布公开版。

公开签发工具的冻结模式把临时解包目录的父目录当作源码根，误拒绝隔离测试的密钥目录。现按运行模式区分源码目录判断，始终拒绝 Git 仓库内的私钥目录。没有终端的命令行运行保留可用标准流，配置错误返回错误码，避免 PyInstaller 致命错误窗口。加入回归测试。

授权主按钮悬停态的白字对比度已校正，三个状态均达到 4.5。Logo、签名协议、机器指纹、私钥来源与原磁盘限制保持相应版本的原有规则。

原授权兼容版与公开版分别验证并交付。生产数据不作为公开构建输入，原部署的私钥和磁盘配置不进入公开仓库。图示属于依据实际控件坐标绘制的布局示意，未代替人工桌面验收。
