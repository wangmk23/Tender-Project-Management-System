# v5.8.40

## 新增

- 旧方式分类同名冲突提供当前流程与现有方式流程对比，以及手动更名或保留待确认维护旧流程的明确入口。
- 共享通用流程列出引用它的采购方式，说明通用模板与独立副本的更新范围。

## 修复

- 保存请求绑定原表单实例与方式标识；旧窗口的成功或失败响应不会改写新窗口或把内容保存到其他方式。
- 项目流程保存期间的新修改保留在编辑器中，并提示重新预览后继续保存。
- 待确认制度的旧方式可直接保存流程，不再被隐藏页签的制度必填项阻断；新方式仍需明确制度。
- 标题随名称、制度草稿更新，新增、移除和排序阶段同步未保存提示。

## 优化

- 离开正在保存的窗口时，明确说明已发出的请求不会被撤销。
- 阶段图标选择使用同一套 SVG 预览与文字名称，支持键盘选择并保留存储值。
- 窄屏压缩重复说明及阶段导航高度，保留四主题和业务密度。

## 其他说明

- 同名唯一性仍按制度约束；不自动改名、合并、删除采购方式或迁移历史项目。
- 默认流程修改只影响之后新建项目；单项目保留预览、完成记录及业务依赖保护。本轮未增加多个命名共享模板。
- 公开版使用自行生成的授权密钥；既有私有部署使用对应兼容成品。授权工具沿用1.8，历史核心仍为编译运行时。
- 本项目代码、界面和说明包含AI辅助编制内容，由维护者整理和验证。
