这一批主要是我对授权中心的界面调整，项目系统仍为 v5.8.14，授权工具为 1.5 版。

- 签发授权、设备信息和密钥管理分为三个页面。
- 使用与系统一致的深色配色、圆角卡片和自绘图标，保留原 Logo。
- 远程机器码、自定义日期和备注按需展开，切换页面保留输入。
- 缩小窗口后，签发按钮仍保持在底部；修复全局字体覆盖标题样式的问题。

建议下载“完整包”，其中包含中文命名的系统和两款授权工具。首次使用需要初始化自己的密钥并签发许可证，管理员初始账号为 `admin`，密码为 `123456`。
