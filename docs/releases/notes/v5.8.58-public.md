# v5.8.58

## 新增

- 项目信息页增加按所选采购方式同步流程的预览与确认入口。
- 进度和任务页增加只读历史区，保留旧流程的完成、不适用、时间及备注。

## 修复

- 已经更换采购方式但仍保留原阶段的旧项目，可以明确确认后同步当前默认流程。
- 完成过部分阶段后更换采购方式，保留原完成和人工跳过记录，按新方式建立后续阶段。
- 服务端阻止旧窗口改写归档阶段，依据真实竞价台账和历史记录保护自建竞价方式。

## 其他说明

- 普通同方式资料保存保持项目自定义流程；新增阶段保持未完成，原完成记录不据此推断到新阶段。
- 未完成阶段有计划、附件或业务依赖时提示处理，不自动删除资料。
- 软件由 AI 辅助编制，历史核心仍为编译运行时。
- 原生桌面、真实设备及3000项目3秒目标仍需独立验收，本版不据此宣称通过。
