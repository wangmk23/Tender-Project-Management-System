# v5.8.56

## 新增

- PDF 预览支持书签、缩略图、页码跳转、全文搜索和打印，适配中文界面、四主题及手机宽度。

## 修复

- 更正采购方式时同步流程，切回时复用原阶段；保留公共记录，遇到已有资料依赖时明确阻止冲突修改。
- 同一采购方式下普通资料更正保留项目个性流程。

## 优化

- 提前并行加载音视频控件，减少首播准备后的额外等待。
- PDF 仅渲染可见页面，改善长文件资源占用。

## 其他说明

- PDF 书签和搜索取决于原文件的目录与文字层，不包含扫描件 OCR。
- 采用自托管 PDF.js、Video.js 和本地 FFmpeg，不把业务附件上传到第三方预览服务。
- 软件由 AI 辅助编制，历史核心仍为编译运行时。
