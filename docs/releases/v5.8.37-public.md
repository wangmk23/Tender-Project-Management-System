# v5.8.37

## 新增

- 采购方式按五类采购制度管理，支持新增、编辑、排序、启停与引用保护；同名方式通过独立标识区分。
- 各方式可设置默认供应商数量、不固定数量、说明和例外，并关联通用或独立流程。新项目保存规则与流程快照。
- 单个项目流程支持预览影响、检查业务依赖后保存；已完成阶段及历史记录受到保护。
- 常规与外观增加跟随系统主题、界面密度、字体、动态效果、默认首页、侧栏显示、日期格式和周起始日等个人偏好。

## 修复

- 采购方式更名后保留网上竞价模块及保存、重载行为。
- 切换采购方式清除继承旧方式的数量例外，保留历史确认记录和独立采购包规则。
- 将数量校验与单项、批量、自动阶段完成放入同一事务，防止并发变化绕过检查。
- 独立流程按实际模块建立检查项和归档目录，避免固定阶段回退及内部标记误报。

## 优化

- 数量不足提供警告、理由和人工确认；默认数量属于管理配置，不自动判为法定数量，不再自动流标。
- 导入导出、保证金默认规则、采购期限参考与重新采购衔接稳定的方式标识。
- 偏好按账号及访问地址隔离，切换外观保留尚未保存的管理员设置；导出年度移至文件与数据。
- 新增界面沿用四主题、图标与业务密度，支持键盘操作及窄屏显示。

## 其他说明

- 全局模板变更不自动改写历史项目。原有方式迁移后制度待管理员确认，确认后用于新项目。
- 数量例外及期限须由管理员结合适用制度、采购文件和实际情况核对；程序不代替法律判断。
- 公开包采用自行初始化的授权密钥，与既有部署兼容升级成品分别提供。授权工具仍为1.8，二进制未改动。
- 可编辑源码覆盖前端及后端扩展；历史V5核心仍为编译运行时，未声称恢复完整核心源码。
- 本项目的代码、界面及说明包含AI辅助编制内容，由维护者整理和验证。
