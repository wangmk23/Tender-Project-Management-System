# v5.8.64 发布验证

Windows 短目录路径关联已加入回归测试。两份固定哈希 EXE 使用真实短路径验证了原件预览和下载。

| 检查 | 本地结果 |
| --- | --- |
| 兼容 EXE | 23 项通过，0 失败 |
| 公开 EXE | 22 项通过，0 失败 |
| Python 全量 | 1363 项通过，28 项条件跳过，0 失败 |
| 前端 | 726 项通过，1 项条件跳过，0 失败。前端内容与 v5.8.63 相同 |

本地成品覆盖自动索引、两层子目录、10,003 份文件的搜索分页、原文件字节与修改时间、权限、同盘移动、PDF 和 Word 预览，以及两页 Word 打印输出。固定输入见[成品清单](v5.8.64-public.json)。

原生目录和打印窗口、物理打印机、实际手机及部署网络属于现场检查范围。


性能目标按本机 Windows 参考环境验收。同一公开 EXE 的 10,003 份文件样本中，各项五次缓存请求均低于 300 毫秒，最高 246.4 毫秒。[原始本机测量](v5.8.64-local-performance.json)包含成品哈希、运行环境和全部样本。

共享 GitHub Windows 主机的首轮测量为 311～338 毫秒，超出本机目标。云端验收分别记录功能检查、本机固定性能证据、云端实测耗时，云端报告中的 hosted_300ms_target_met 直接说明该主机是否达到 300 毫秒。没有提供匹配成品和运行时的本机证据时验收失败。
