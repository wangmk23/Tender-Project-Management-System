# 项目起止时间表

图表看板底部自动列出当前账号可查看的项目，显示项目名称与编号、采购方式、状态、创建时间、结束时间及历时。支持名称/编号/方式搜索、状态筛选、创建或结束时间排序、历时排序，每页20项；点击项目名称进入详情。

- 创建时间读取项目原有数据库记录，SQLite中的创建时间按原模型UTC解释，界面统一按北京时间显示并沿用日期格式偏好。
- 正常完成须全部有效阶段已完成或已跳过；已移除阶段不参与判断。结束时间取已实际完成且未跳过阶段的最晚完成时间，不使用计划时间、不适用阶段日期或模板顺序。实际完成记录缺失时显示“未记录”。撤销完成、增加未完成阶段后回到进行中。
- 终止、流标、废标在成功变更状态的同一事务内保存实际操作时间。重复保存说明不刷新结束时间；恢复项目清除当前结束时间，再次结束重新计时。不同结束结果保留原状态名称，不混为已完成。
- 历史已结束项目缺少可靠结束记录时不按升级时间补写。历史创建时间缺失、日期无效、结束早于创建或记录在未来时，不猜测历时；异常显示“时间待核对”。最晚完成日存在只有日期的阶段记录时，项目结束时间也只显示日期，不假定精确时刻。
- 历时按北京时间的自然日期差，同日0天，进行中计至今天，已结束计至结束日；不扣除节假日，不等同法定办理期限。创建精确到秒、阶段完成精确到分时，同一分钟不判为倒置。
- 时间表使用已有项目列表响应，结束时间读取批量查询一次；筛选分页在本地完成，不逐项目请求。跨日再次进入看板时更新进行中历时。

本功能新增独立的项目结束日期辅助表，不改写项目、阶段、业务附件或授权记录；不提供手动改写历史时间的入口。原始核心仍为编译运行时，软件由AI辅助编制。
