# 维护者本地交付布局

维护者按下列编号目录整理源码与成品。这是本地交付总目录的布局，并非本GitHub仓库的内部结构。

| 用途 | 入口 |
| --- | --- |
| 接手及当前版本记录 | `00-接手与使用入口` |
| 最新公开维护源码 | `01-当前源码/项目管理系统-公开版` |
| 开发与交付记录 | `02-开发记录` |
| 自绘彩色图标规范 | `03-开发规范与界面风格` |
| 最新系统和授权成品 | `04-发布成品/公开版-v5.8.14` |
| 交付校验记录 | `05-清理与归档清单` |
| 公开版源码与交付快照 | `06-分版本源码/项目管理系统-公开版-v5.8.14` |
| 公开仓库Git历史备份 | `07-完整仓库备份` |
| 公开授权工具源码和成品 | `10-授权工具/公开版-v5.8.14` |
| 公开发布准备与历史材料 | `11-公开发布` |

每次交付同步当前源码、成品、快照、授权工具、校验、索引和交接；保留历史版本。公开源码中不包含历史核心后端的完整Python源文件，构建仍需要公开运行时EXE。业务数据库、私钥和设备配置不放进源码快照或Git备份。

用户从GitHub下载Windows完整发布包并按README使用即可，无需创建这些维护目录。成品生成及校验不代表已切换维护者正在运行的系统。
