# 国家参考采购方式与流程（v5.8.38）

“系统设置 → 项目流程”现在提供20项已分类的参考配置。以2026年10月18日本轮核对的国家层面正式文件为依据，不加入地方交易规则，不采用征求意见稿作为生效依据。它们是可编辑的流程起点，不是程序对某个具体项目作出的法律适用判断。

| 适用制度 | 新增参考方式 |
| --- | --- |
| 政府采购 | 公开招标、邀请招标、竞争性谈判、竞争性磋商、询价、单一来源采购、框架协议封闭式第一阶段、框架协议开放式第一阶段、框架协议第二阶段、合作创新采购 |
| 依法必须招标的工程建设项目 | 公开招标、邀请招标 |
| 企业及国有企业自主采购 | 公开招标、邀请招标、询比采购、竞价采购、谈判采购、直接采购 |
| 集体经济组织采购 | 全国通用管理参考 |
| 其他采购 | 通用管理参考 |

每项配置均有独立阶段，可展开“国家参考预设”或“通用管理参考”查看适用说明、依据链接和核对日期。管理员修改后显示“已调整”，依据仍标明是初始参考，不宣称修改后的配置当然合法。

政府采购货物服务与工程招标采用不同的阶段。工程招标将候选人公示和最终中标结果分开；磋商和谈判采用不同的评审节点。框架协议第一阶段与第二阶段分别建项目，第二阶段按框架协议核对直接选定、二次竞价或顺序轮候等方式。合作创新另设创新概念交流、研发谈判、研发合同和首购协议、研发评估及验收等节点。

企业参考流程不将央企指导意见的适用范围扩大到全部企业或地方国企，也不把政府采购的数量规则强加给自主采购。集体经济与其他采购不编造全国统一的限额、平台和公告期限。企业竞价节点用于登记外部报价凭证及结果；不会把多轮竞价套为既有的一次报价模块。

数量配置只作管理预警：常规竞争方式预设三家、单一来源预设一家；框架协议、合作创新及自主采购等保留“不固定最低数量”，由管理员核对适用条款后配置。法律规定的例外不自动启用，不改变既有的名单核对和人工确认机制。未自动设置法定期限、倒计时或到时完成。

## 数据保护

- 升级只新增独立的方式配置和来源登记，不重分类旧方式，不改旧项目、采购包、阶段、名单、中标结果、保证金和期限。
- 原八项迁移配置仍保留原名称、标识、制度、数量和流程。名称相同也不会把旧项目换绑到新预设。
- 同一制度已有同名配置时保留已有配置，不覆盖，也不冒充该项已采用国家参考流程。
- 管理员更名、改流程、停用或删除预设后，重启不覆盖、不重新启用、不重新添加已删除的项。
- 达到200项目录上限时不删除或覆盖原项；未能添加的数量会提示，后续有空间时可在重启后补齐。
- 所有预设随程序附带，启动时不下载规则、不执行远端代码。点击官方依据链接才会打开相应网页。

## 官方依据

- [政府采购法（2014年修正）](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_47b5807c40c040368eb5f13b489d6c43.html)：采购方式及政府采购适用范围。
- [政府采购非招标采购方式管理办法](https://www.mof.gov.cn/gp/xxgkml/tfs/201401/t20140102_2510302.htm)：谈判、单一来源和货物询价。
- [竞争性磋商办法](https://www.mof.gov.cn/gkml/caizhengwengao/wg2015/wg201502/201506/t20150611_1256070.htm)、[补充通知](https://www.mof.gov.cn/gp/xxgkml/gks/201511/t20151102_2511411.htm)：磋商程序及特定例外。
- [框架协议采购办法](https://dl.mof.gov.cn/tongzhitonggao/202201/t20220128_3785704.htm)：两种征集形式与第二阶段合同授予。
- [合作创新采购办法](https://www.mof.gov.cn/jrttts/202404/t20240429_3933787.htm)：研发与首购衔接。
- [招标投标法（2017年修正）](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_1f79dd79321441a0831f3aed697b4535.html)：公开和邀请招标及基本程序。
- [规范中央企业采购管理指导意见](https://www.gov.cn/zhengce/zhengceku/202408/content_6966835.htm)：央企采购规则及其适用边界。
- [农村集体经济组织法](https://fgs.moa.gov.cn/flfg/202409/t20240911_6462349.htm)：组织决策、集体财产与公开监督原则。
