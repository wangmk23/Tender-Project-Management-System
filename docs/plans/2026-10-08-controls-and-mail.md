# 控件、图标与邮件设置修正

按用户提供的实际界面修正以下问题，沿用现有页面布局与业务流程。

1. 阶段图标选择器预览层包裹原 select 后，尺寸选择器失效。统一控件高度、内边距与箭头位置，保留阶段存储值。
2. 批量推进和其他带图标的下拉选项共用自绘图标渲染，保留原键盘导航、值和变更事件；不改业务文本与 logo。
3. 邮件设置拆分连接、账号及发送计划，避免说明文字拉低相邻输入框。密码保持留空不修改的加密保存机制。
4. 授权工具沿用三页布局，修正原生控件的浅色边缘和圆角被内层覆盖问题，统一状态、输入、按钮及滚动条。

验证使用隔离数据、浏览器渲染和原生 Tk 控件检查，不自动启动或重启用户运行中的系统。生产邮箱配置与测试仅在本机进行，公开源码、测试和发布包不包含账号或授权码。

本地普通升级保留原许可、公钥与数据加密模块。系统与授权工具分别交付到所属目录，先完成中文命名成品、快照、备份与校验，再发布脱敏自建密钥公开版。
