# 有效投标、保证金期限与节假日日历

用户已确认合并开发。适用版本 v5.8.27；沿用现有程序身份、授权、数据库及界面主题。

报名不等于参加，参加不等于有效投标，有效投标不等于实际缴纳保证金。按报名记录 ID 和采购包识别供应商，联合体作为一个投标主体。开标/评审中登记待确认、未参加、未提交文件、文件未接收、有效、无效；异常必须有原因。结果公告新增及修改供应商只能选择已确认有效者，后端同样检查。新规则首次启动记录历史阶段快照，已完成的结果公告及项目保持原数据与选项。未完成公告的旧项目保留已录入结果，之后新增/修改必须先核对。禁止批量自动将报名人员变成有效。

实际缴纳记录独立保存：未知、未缴、已缴，金额及已退金额；无效或未参加但实际缴纳仍有待处理事项。处理状态按规则、待核实、暂缓，暂缓必须原因与复核日期，不能隐藏原截止日。部分退款只减少余额，全部退款停止提醒。无需保证金不新增自动任务，但已存在缴纳记录不可隐藏或抹除。

规则按项目/采购包、对象（中标/未中标/异常）配置，选择真实起算阶段 ID 或手动实际日期，天数、自然/工作日、截止时分、提前提醒。默认关闭，用户确认实际依据后启用，不按采购方式强制选法律预设；委托协议不视为采购合同。完成触发阶段以实际完成日期计算；撤销/改期提示需复核，不自动丢弃期限或退款历史。归档/100%不停止未退事项提醒。旧项目不自动生成或群发历史期限。后台重复扫描、重启、失败重试可恢复，去重按事项/期限版本/提醒日期/收件人。

内置2026国务院国办发明电〔2025〕7号放假和调休，工作日含周末补班、排除全部放假日，从次日起数。未覆盖年份不估算，提示待确认。日历区分假日暖色、补班蓝色、普通周末灰色，文字休/班和节日名，主题一致，不覆盖选中/今日边框和上层事件。以一套权威数据用于显示、计算和可选工作日邮件。后续在线更新读取本仓库经官方核验的版本化数据，验证年度/来源/摘要与结构，原子替换失败保留本地数据；改变已生成截止日需明确复核。

邮件新事件类型保证金到期/待核实复核，沿用SMTP、加密凭据、收件组、主题预览测试。不自动发供应商账号；真实测试仅发送已授权的测试邮箱，业务测试使用隔离数据与模拟SMTP。程序关闭不能发信，启动只补当前有效事项，不补发大量历史信。

后端采用独立扩展表和模块，历史核心仍编译运行时。仅测试隔离临时目录，不自动替换E:/系统/项目系统。正式本地编号目录交付完成，再GitHub发布v5.8.27，标题仅版本号，中文附件标签，保留AI声明与MIT。
