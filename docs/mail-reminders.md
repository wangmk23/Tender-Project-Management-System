# 邮件提醒的操作与验证

先填写邮箱服务器、登录账号、发件地址和 SMTP 授权码。QQ / Foxmail 使用 SSL 465；不要把网页登录密码填在授权码栏。密码由 Windows 加密保存，读取设置时不返回密码。

主页面保存星期、时间、提前天数和节点。星期一至星期日均可选择，至少保留一天；提醒节点至少选一个。启用自动提醒是每日节点与供应商预警调度的总开关，新建和完成项目有各自的总开关。

默认收件组的六个内容字段跟随主页面保存；其他收件组的内容和订阅在组内设置。每个启用的组至少要有收件邮箱、提醒类型和适用的内容字段。共用邮箱在正式调度中合并匹配的字段，每封邮件只显示自己的收件地址。组预览和测试只展示该组选择的内容。

预览、组测试使用示例资料，不保存编辑草稿。主页面的“发送测试邮件”验证连接并保存成功的邮件配置，失败时保留原配置和密码；组测试有 60 秒冷却。SMTP 接受邮件表示服务器已接收，不能据此保证收件箱已显示邮件。

项目事件首次扫描只建立基线，避免给已存在或已完成的历史项目补发通知。之后的新建与完成事件各自发送一次。事件检测与每日节点计划分开；首次打开事件开关后，等待建立基线，再用新项目验证。

每日提醒到设定时间后，按选择的星期检查当天至提前天数范围内的计划节点。已完成、跳过和终止项目不列入阶段提醒。失败的收件人最多重试三次，间隔 15 分钟；成功收件人不重复发送。当前开关、订阅、字段规则或节点状态已失效时暂停旧任务；恢复相同订阅且节点仍在有效窗口内才允许继续重试。发送过程中断且无法确认结果时保留状态，避免盲目重复投递。

回归范围包括七天和六字段保存重载、竞价节点、自定义模板、草稿保护、总开关、四类提醒路由、去重与隐私、时间窗口、重启基线、失败重试、状态文件损坏、SMTP SSL / STARTTLS、证书校验及连接释放。浏览器交互测试使用无头 Chromium；成品测试使用独立目录、示例项目和临时自建密钥，不改变原业务数据库和授权。

本版验证记录（2026-10-08）：前端 262 项通过；Python 607 项中 587 项通过、20 项依赖额外成品或测试条件而跳过。另对公开成品提取的邮件函数执行 135 项回归，全部通过；公开成品 9 项邮件检查、本地兼容成品 8 项邮件检查及公开系统 13 项基础检查通过。真实 SSL SMTP 接受两封指定收件地址的示例测试邮件；未验证收件箱到达。日历名称与图标在实际成品和无头 Chromium 中一致，未进行可见桌面人工验收。
