# 保证金缴退与邮件设置

适用版本：v5.8.30。

## 保证金金额

新建项目直接填写“保证金金额（元）”，手动输入，不使用数字增减按钮。分包留空时沿用项目金额。勾选“无需投标保证金”后，项目和分包金额框一并隐藏；取消勾选会恢复未保存的输入，不清空历史金额。

无需保证金的项目仍要核对实际参与、文件接收与投标有效性。该区域不再显示金额设置、缴纳状态和登记缴款。已有真实缴款未退清时，保留“处理历史退款”入口。

## 足额缴款与全额退还

新核对的实缴金额低于采购文件要求时，默认按“未参加”处理并记录不足额原因；实际到账金额仍保留，继续进入保证金退还管理。未缴且应缴大于零时同样处理，缴纳情况未知时仍待核实。足额缴纳不会自动确认有效投标，仍需核对文件提交、接收与有效性。

在金额要求调整后，新的中标结果、公告完成及通知书仍检查当前金额，不允许通过旧的有效状态绕过不足额限制。历史已完成结果保持原政策，不改写其供应商或参与记录；修改金额、退款、调整退还规则本身也不会批量改写参与记录。

普通退款只需确认已将待退余额全额退还，不再逐笔填写退款金额。历史部分退款保留，下一次全额退还只结清剩余余额。系统不会直接操作银行转账，必须在实际完成退款后登记。实缴金额和原期限保留；特殊更正仍需要明确说明和审计记录。

## 邮件设置分工

外层设置发件账号、服务器、时间、提前天数、星期、国家工作日安排、主题及所有阶段提醒共用的节点范围。通用节点和采购方式专有节点分组显示。收件组统一设置邮箱、主题前缀、提醒类型和邮件内容，原默认组按普通组编辑；不再重复展示默认组邮箱、六项内容或项目事件订阅开关。

内容按公共项目信息、阶段提醒、项目新建与完成、报名与供应商不足、保证金退还与复核分类，仅显示已选类型可用的字段。公共信息是本组各类型共用设置，未引入一套隐藏的独立字段规则。取消某类型再勾回时，已选内容保留。

停用收件组会停止该组订阅；同一收件人匹配多个组时，按事件合并字段，沿用首个匹配组的主题前缀，继续使用原队列去重与重试机制。公共安排的保存不提交空的旧收件人或旧内容选项，避免覆盖已有订阅。预览与组测试规则保持原有行为。

## 响应与验证边界

日期控件原来在无关节点的属性或内容变化后，也会执行两次整页查询。现在只检查新增、变化的日期控件及其所在区域；弹窗关闭、动态字段、禁用状态和键盘交互仍有回归验证。阶段滚动区增加边界限制和稳定的滚动条空间。

100张供应商卡片、四倍CPU限速的本机无头对照未复现超过25毫秒的滚动帧；移除模糊也没有稳定改善，因此本版没有据此移除现有视觉效果。该结果不能证明实际使用电脑不卡顿，仍需在对应电脑复核。上一版接口测量的范围见[响应说明](response-performance.md)。
