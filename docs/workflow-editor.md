# 采购方式与流程

系统设置 → 项目流程保留五种采购制度分类。同一名称在不同制度下是不同配置，不自动合并。

选择左侧采购方式，右侧查看阶段名称、顺序和业务模块。点击“编辑流程”，或点击某一阶段，进入居中的流程编辑弹窗；点击阶段时定位该阶段。页面预览不直接编辑。

弹窗左侧是阶段目录，右侧配置名称、图标及业务模块。支持键盘上下键、Home、End 选择阶段；可在当前阶段后插入，或用“阶段位置”直接排序。修改暂存在窗口内，点击底部“保存流程”后提交；取消或关闭未保存窗口会要求确认。保存冲突或失败时草稿保留。

通用默认流程由多个方式共用。如需只改一个方式，先“改为独立流程并编辑”。保存独立流程不影响其他方式，也不修改已有项目。

## 沿用旧配置

已分类方式在同名的旧配置存在时，编辑窗提供“沿用之前保存的…流程”。展开并点击“复制原有流程到当前草稿”，核对后正常保存。只复制阶段内容，不改变源配置、采购制度、数量规则、保证金规则或历史项目；保证金规则引用的阶段如不兼容，保存会明确拒绝，草稿仍在。

“待确认制度 · 原配置”保留以前的模板和引用关系，可查看和维护，不会猜测采购制度。v5.8.44 专属模式已撤回：新版本显示正常分类，忽略其隐藏配置，但保留激活后手动修改的模板及审计表，不将旧快照强行写回。

此功能不自动同步或覆盖已建立项目的流程。各采购方式的独立副本保存后可以分别修改。

## 使用的采购制度

顶部开关按五种制度自动保存。升级时保留当前可选范围，管理员可关闭不用的制度，避免新建项目时浏览大量同名方式。停用后新建、改选、重新采购、项目导入模板不再提供对应方式；接口也校验状态，避免旧客户端继续创建。

停用只改变可选范围，不删除采购方式、默认模板、保证金配置或项目记录。管理页仍可维护停用制度的配置；历史项目保留原方式并可继续编辑。侧栏保留已有项目的历史选项。重新启用制度后恢复可选范围，单独停用的方式保持停用。

通用流程采用紧凑预览，顶部“复制为独立流程并编辑”可进入原有阶段编辑器；复制前通用模板只读，复制草稿取消时不改变模板。
