# 采购方式与流程

系统设置 → 项目流程用于自行创建、维护采购方式及默认模板。已取消制度分类与开关。原有配置保留，同名历史配置分别维护，不自动合并；编号依据稳定标识排列，不随列表上移、下移改变。

选择左侧采购方式，右侧查看阶段名称、顺序和业务模块。排序、启停及删除位于摘要附近；已有项目或采购包引用的方式不能删除，可改为停用。切换方式保留左侧列表、焦点与滚动位置。

点击“编辑流程”，或点击某一阶段，进入居中的编辑弹窗；点击阶段时定位该阶段。右侧页面预览保持只读。

弹窗左侧为阶段目录，右侧配置名称、图标及业务模块。支持上下键、Home、End选择阶段，可在当前阶段后插入，或通过“阶段位置”排序。内容先保存在草稿中，底部“保存流程”后提交；关闭未保存窗口会要求确认。保存冲突或失败时保留草稿。

通用默认流程由多个方式共用。需要只修改一种采购方式时，点击“复制为独立流程并编辑”。独立副本保存不改变通用模板、其他方式或已有项目。替换不同的独立草稿前会确认。

保存成功而刷新失败时，提示“内容已保存，列表暂未刷新”，可单独“重试刷新”。表单保留已保存的标识与版本，重复刷新不会再次新增；保存期间继续输入的内容保留，仍须另行保存。

数量规则是管理配置，不直接代表法定最低数量。固定数量须为1至99的整数，例外须填写名称及适用说明；错误时自动展开并定位字段。不固定数量时隐藏无用的最低数量框。普通账户仅能查看规则。

默认模板只用于之后创建的项目，保存不会同步覆盖原项目。单项目流程调整须先预览影响；已完成阶段、业务依赖及保证金起算关联继续受保护。v5.8.44专属模式已撤回，不再执行隐藏或自动覆盖。
