# 节日当天与放假调休模板

v5.8.49 将“节日名称”与“放假、补班状态”分开。日历只在节日当天显示节名，假期其他日期显示“休”和原有底色，调休上班显示“班”。不改变现有工作日计算和已确认业务期限。

## 填写步骤

1. 在日历“安排与更新”中选择年度，下载空白模板。
2. 先看“填写说明”的三行示例，再切换到“放假调休安排”，从第2行填写全年安排。
3. 保存为 `.xlsx`，回到系统选择相同年度，上传预览。
4. 分别核对放假日期数、补班日期数、节日当天数及业务影响，再确认生效。

客户端保存在设置中的文件保存位置，并显示完整路径；浏览器交给浏览器下载。重复下载不会覆盖原文件。

| 列 | 填法 |
| --- | --- |
| 开始日期 | 必填，所选年度内的日期，例如 `2026-10-01` |
| 结束日期 | 单天留空；区间填最后一天，包含该日。节日当天只能单日 |
| 类型 | 下拉选择“放假”“补班”或“节日当天” |
| 名称 | 节日当天必填，1至40个字；放假、补班行可留空，仅作为安排说明 |

以2026年国庆安排为例（说明页示例不参与导入，实际填写页保持空白）：

| 开始日期 | 结束日期 | 类型 | 名称 |
| --- | --- | --- | --- |
| 2026-10-01 | 2026-10-07 | 放假 | 国庆假期 |
| 2026-10-01 | 留空 | 节日当天 | 国庆节 |
| 2026-10-10 | 留空 | 补班 | 国庆调休 |

效果是10月1日显示“国庆节”和“休”，2至7日只显示“休”，10日显示“班”。节日行可以与放假、补班行重叠，但不能重复登记同日节名；同日多个节日可合并填写名称。休班日期不能彼此重叠。普通周末不用填写，跨年分年度。

## 兼容与更新范围

- 导入完整替换所选年度，请填写全年完整放假、补班及需要显示的节日当天。新格式未填写节日行时不显示节名，不会从假期首日推断节日。
- 旧四列表头“开始日期、结束日期、安排、节日名称”仍支持。旧格式的名称保留为假期说明，2026年显示已核验的节日当天，其他年度需要用新模板补充日期。不自动修改旧日历文件、修订哈希或原确认期限。
- 导出当前安排包含三种记录，再导入会保留休班日期和当天节名；支持无放假安排的自定义节日标注，标注本身不增加休假。
- 粘贴可能绕过表格校验，上传后仍逐行检查。保留公式、宏、外链、跨年、压缩包及重复日期校验。
- 成品测试使用隔离数据与无头浏览器；原生WebView和全部Excel/WPS版本不视为已人工验收。

## 日期依据

2026年休假及补班日期按[国务院办公厅2026年部分节假日安排通知](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。节日当天另行核对：[香港天文台2026年公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)，例如春节为2月17日，清明为4月5日，不直接采用放假区间第一天。内置当天标注只覆盖已核验的2026年七个主要节日，不推测未核验年度的农历节日，也不改变年度安排是否已确认的状态。
