# 源码与运行时边界

本仓库是现有 Windows 应用的公开维护版本。以下内容可以阅读、修改和按构建流程集成：

| 目录 | 内容 |
| --- | --- |
| `source/frontend/` | 按功能拆分的前端 JavaScript 源码和拼装清单 |
| `src/backend_patches/` | 项目流程、安全、设备准入、附件和业务扩展代码 |
| `src/templates/` | 供构建流程使用的界面模板 |
| `src/project_manager/static/` | 页面样式、生成的前端脚本及第三方静态资源 |
| `authorization/` | 授权工具源码，使用部署者自行生成的密钥 |
| `tools/` | 前端生成、编译扩展、归档替换与公开构建工具 |
| `tests/` | 前端、扩展与打包行为的回归测试 |

历史核心应用和部分运行依赖来自 PyInstaller 打包运行时。其完整 Python 源文件目前不在本仓库中。构建工具读取指定 EXE 的归档，将公开维护的资源与扩展集成到输出 EXE；这不是从完整核心源码重新编译的流程，也不保证不同环境生成完全相同的字节。

二次构建需取得公开发布的脱敏运行时，并核对其 SHA-256。不得使用包含真实数据库、组织信息、历史密钥或内部路径的私人部署 EXE 作为公开发布基线。构建输入和输出路径必须不同。

仓库 MIT 许可适用于项目原创代码。第三方资源和运行依赖适用其原有许可；发布 EXE 时仍须一并保留相关版权与许可说明。二进制运行时的完整依赖清单应随实际 Release 补齐，不能把静态资源许可表当作完整软件物料清单。
