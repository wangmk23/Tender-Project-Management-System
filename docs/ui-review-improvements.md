## 补充修复

- 项目信息页“无需保证金”复选框原先因事件冒泡发生两次切换；现在一次点击只提交一次实际选择。
- 阶段侧栏纳入弹窗焦点管理；打开时立即可见，减少动态效果设置不再阻止焦点进入；Ctrl+E保持阶段快捷保存，嵌套弹窗优先处理。
- 成品构建采用经过审查的受控源码模板，并递增静态资源缓存键。公开构建保留处理后的模板，避免再次用原始HTML覆盖缓存版本。
