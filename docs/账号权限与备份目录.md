# 账号权限与备份目录

管理员在账号管理中选择“管理员、协作编辑、只读查看”。协作编辑可分别设置新建项目、编辑业务、删除项目、附件管理和导出权限；只读查看仅可选导出权限。管理员始终保留完整权限。原有普通账号升级后仍可新增、编辑、管理附件及导出，删除项目仍需管理员单独授权。

权限由服务器检查，对已经登录的会话同样生效。普通权限拒绝不会重放写入，页面保留原草稿。最后有效管理员及当前管理员自身的降权、停用和删除仍受保护。只读访问保留项目、附件与文档预览；预览读取不提供防复制保护。

主机客户端的管理员可在设置中输入或选择备份目录，点击保存后用于后续自动备份。恢复默认会清除自定义配置。文件夹须为完整绝对路径且可写；用户显式选择可写目录时可使用 C 盘，默认位置沿用非 C 盘策略。外链与手机的文件系统属于访问设备，主机目录选择和打开功能仅在主机客户端提供。

更改目录不移动、删除或重新生成已有备份。不可写路径或配置保存失败保留旧设置；已配置目录失效时备份明确失败，不擅自转存其他位置。可回到设置重新选择。自动备份仍使用原有加密、备份内容和保留规则。

授权工具的密钥保存路径可以点击或用 Enter、空格打开文件夹。公钥导出成功后显示的是本次实际输出目录；随后更改表单不会改变该链接指向。打开文件夹不会打开密钥文件、重新导出密钥或更换原有磁盘绑定规则。
